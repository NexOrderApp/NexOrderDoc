Microservice Specifications & Code-Level Details

Detailed functional breakdown and technical implementation graphics for each service.

NexOrder.ProductService

Product Catalog Management, Semantic Kernel AI & Hybrid Caching Pipeline

Repository

Functional Capabilities

  • Product catalog creation, metadata updates, and inventory tracking.
  • Category hierarchy lookup and entity relationship management.
  • AI-assisted product search prompt processing via Semantic Kernel.
  • Sub-millisecond entity caching for hot product listings.
Implementation Flow: ProductService

Semantic Kernel AI

Integrates Microsoft Semantic Kernel to parse product attributes and execute AI-assisted catalog queries using custom plugins and structured prompts.

Distributed Caching

Uses IDistributedCache backed by Azure Cache for Redis and FusionCache to prevent database cache stampedes on hot items.

Security & Isolation

Fetches storage connection parameters from Azure Key Vault, encapsulating product catalog entities inside an isolated Azure SQL database context.

NexOrder.OrderService

Order Processing Core & Lifecycle State Management Subsystem

Repository

Functional Capabilities

  • Order placement ingestion and line-item total calculations.
  • Order lifecycle state machine handling (Pending, Processing, Completed, Cancelled).
  • Transactional customer purchase history lookups.
  • Checkout request payload validation against product line items.
Implementation Flow: OrderService

Technical Implementation

  • Isolated Persistence: Uses a dedicated Azure SQL database instance strictly bound to the order domain.
  • Secrets Ingestion: Connects to Azure Key Vault on application startup to load database connection parameters.
  • Framework Integration: Leverages `NexOrder.Framework` shared middleware for error handling and standard responses.

Infrastructure Interaction

  • Managed Identity authentication for zero-plaintext credentials access to Azure resources.
  • Centralized telemetry reporting via Application Insights for order processing flow analysis.

NexOrder.UserService

User Profile Management & Customer Address Subsystem

Repository

Functional Capabilities

  • Customer profile management and personal detail updates.
  • Shipping and billing address book management.
  • User contact details resolution during checkout operations.
  • Account preferences and metadata persistence.
Implementation Flow: UserService

Technical Implementation

  • Data Isolation: Dedicated Azure SQL instance ensuring personal user data identity isolation.
  • Azure Key Vault Integration: Dynamic secrets loading for storage connection strings.
  • Shared DTO Contracts: Utilizes unified API response wrappers from `NexOrder.Framework`.

Infrastructure Interaction

  • Secure credential management using Azure Key Vault configuration provider.
  • Isolated database deployment maintaining total autonomy from sales and product schemas.

NexOrder.AuthService

Identity Verification & Access Control Subsystem

Repository

Functional Capabilities

  • User registration, login credentials processing, and password verification.
  • JWT access token generation and signing key validation.
  • User identity claims emission and role verification across API endpoints.
  • Authentication state enforcement for secure microservice interactions.
Implementation Flow: AuthService

Technical Implementation

  • Dynamic Key Vault Secrets: Ingests authentication signing keys and database credentials via Azure Key Vault.
  • Isolated Storage Context: Dedicated Azure SQL database isolating authentication secrets and credentials.
  • Framework Middleware: Standardized error handling and API response envelopes.

Infrastructure Interaction

  • Azure Key Vault provider dynamically fetching JWT signing keys at runtime.
  • Zero static credentials saved in repository settings files.

Azure Infrastructure & Resource Management

Azure Key Vault

Centralized secret management. Injects sensitive database connection strings, JWT signing keys, and external service credentials directly into standard .NET appsettings during host initialization.

Azure Cache for Redis

Managed distributed memory store backing the .NET IDistributedCache interface and FusionCache in ProductService for sub-millisecond retrieval of catalog entity payloads.

Azure SQL Databases

Fully managed relational database instances providing physical data boundary isolation per microservice context (Product, Order, User, and Auth).

Azure App Service / Container Apps

Hosts containerized .NET Web APIs with independent scaling configurations across microservice instances.

  • Independent Scaling: Scales microservices independently based on compute and request traffic demands.
